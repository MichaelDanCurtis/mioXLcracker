# Hardware Documentation

This folder contains documentation for the mio XL MIDI interface hardware and related communication protocols.

## Contents

- [mio XL Hardware Overview](mio_xl_overview.md) - General information about the mio XL MIDI interface
- [Protocol Specifications](protocol_specifications.md) - Communication protocols and specifications
- [Connection Guide](connection_guide.md) - How to connect and communicate with the hardware

## About mio XL

The mio XL is a USB MIDI interface manufactured by iConnectivity. It provides multiple MIDI I/O ports for connecting MIDI devices to computers and other hardware.

## Purpose

This documentation is intended to support the analysis and reverse engineering of the mio XL hardware communication protocols for educational and development purposes.
